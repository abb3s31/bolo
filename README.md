# 🏛️ منظومة إدارة مسار بولونيا الأكاديمي الشاملة
### جامعة الإمام جعفر الصادق (ع) - فرع ميسان 🇮🇶

منظومة إلكترونية سحابية متكاملة مصممة خصيصاً لإدارة العملية التعليمية وحساب السعيات الفصلية والنهائية، وتكليفات الأساتذة، وترحيل الطلاب وتوثيق الشهادات وفق معايير **مسار بولونيا (Bologna Process)** المعتمد من وزارة التعليم العالي والبحث العلمي العراقية.

---

## 🌟 مميزات المنظومة الرئيسية

1. **🏢 إدارة الأقسام الأكاديمية الـ 12 والمراحل الـ 48**:
   - تغطية شاملة لجميع أقسام فرع ميسان (هندسة تقنيات الحاسوب، القانون، العلوم المالية والمصرفية، هندسة البرمجيات، إدارة الأعمال، المحاسبة، الإعلام، اللغة الإنجليزية، علوم القرآن، الأجهزة الطبية، التربية البدنية، والتصميم الداخلي).
   - تقسيم دقيق لكل قسم إلى 4 مراحل دراسية (إجمالي 48 مرحلة).

2. **👑 نموذج الأمان الصارم وانعدام الثقة (Zero-Trust Security Hierarchy)**:
   - **المسؤول العام (`super_admin`)**: الصلاحية الحصرية المطلقة لإنشاء وتعديل الأقسام وتعيين رؤساء الأقسام والمقررين وإدارة الخطة الأكاديمية.
   - **رؤساء الأقسام والمقررون (`department_head` / `rapporteur`)**: إدارة متكاملة لبوابة القسم الأكاديمي، تكليف الأساتذة بالمواد، متابعة نسب الإنجاز، وترحيل الطلاب بين المراحل والتخرج.
   - **الأساتذة التدريسيون (`teacher`)**: رصد الدرجات اللحظي لبنود مسار بولونيا الـ 7 مع قفل السعيات وتصدير التقارير.
   - **الطلبة (`student`)**: استعراض كشف الدرجات التفصيلي، ساعات ECTS، وحالة السعي ووثائق الـ QR المعتمدة.

3. **📊 احتساب السعي ببنود مسار بولونيا الـ 7 (سعي 50 + نهائي 50 = 100)**:
   - **الكويز الأول (Quiz 1)**: 5 درجات
   - **الكويز الثاني (Quiz 2)**: 5 درجات
   - **الواجب الأول (Assignment 1)**: 5 درجات
   - **الواجب الثاني (Assignment 2)**: 5 درجات
   - **التقرير والنشاط (Report)**: 10 درجات
   - **الامتحان النصفي (Midterm)**: 10 درجات
   - **الجانب العملي/المختبر (Practical)**: 10 درجات
   - **الامتحان النهائي (Final Exam)**: 50 درجة

4. **🚀 نظام ترحيل وتخرج الطلاب الذكي**:
   - ترحيل فردي وجماعي للناجحين (مرحلة 1 ⬅️ مرحلة 2 ⬅️ مرحلة 3 ⬅️ مرحلة 4 ⬅️ خريج مؤهل بنجاح 🎓).
   - توثيق فوري في سجلات التدقيق وإرسال إشعارات فورية للطلبة.

5. **🔲 التحقق الرقمي الموثق بالـ QR Code**:
   - إصدار وثائق رسمية وكشوفات درجات مشفرة يمكن التحقق من صحتها فورياً عبر مسح رمز الاستجابة السريعة QR.

6. **📑 التصدير والطباعة الاحترافية**:
   - تصدير تقارير الإكسل الإحصائية (`xlsx`)، وطباعة كشوفات السعي الرسمية (`PDF`) بختم الجامعة وترويستها الرسمية.

## 🛠️ التقنيات المستخدمة

- **الواجهة الأمامية (Frontend)**: Next.js 16 (App Router + Turbopack) + React 19 + TypeScript.
- **التصميم والتنسيق (Styling)**: TailwindCSS + Lucide Icons + خطوط عربية حديثة تدعم الاتجاه الكامل RTL.
- **قاعدة البيانات (Database & Backend)**: Supabase PostgreSQL + Row Level Security (RLS) + Triggers + Realtime.
- **إدارة الحالة ومزامنة البيانات**: Context API + Supabase Client + Local Storage Fallback للاستخدام دون اتصال.

## 🚀 تشغيل المشروع محلياً (Local Setup)

### 1. تثبيت الحزم والمكتبات
```bash
npm install
```

### 2. إعداد المتغيرات البيئية (`.env.local`)
أنشئ ملف `.env.local` في المجلد الرئيسي وضمنه مفاتيح مشروعك في Supabase:
```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
```

### 3. تطبيق سكربت قاعدة البيانات السحابي
انسخ محتويات الملف الكامل المجهز:
```text
supabase_schema.sql
```
والصقه في **SQL Editor** داخل لوحة تحكم Supabase واضغط على **Run**.

### 4. تشغيل خادم التطوير
```bash
npm run dev
```
افتح المتصفح على: [http://localhost:3000](http://localhost:3000)

### 5. فحص وبناء الإنتاج
```bash
npx tsc --noEmit
npm run build
```
